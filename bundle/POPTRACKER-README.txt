Reignited AP — PopTracker pack
==============================

Optional. A PopTracker pack for the randomizer. PopTracker is a separate
desktop tracker app (https://github.com/black-sliver/PopTracker/releases);
you do not need it to play.

INSTALL
  1. Install PopTracker (v0.31.0 or newer).
  2. Copy the "spyro_reignited_ap" folder next to this file into PopTracker's
     "packs" folder.
  3. Start PopTracker, pick the "Spyro Reignited Trilogy" pack, and choose the
     "Archipelago" variant.
  4. Use its Archipelago connection to point at your server and slot.

The pack ships placeholder map backgrounds. See the pack's source repository
for how to overlay your own extracted minimaps.
