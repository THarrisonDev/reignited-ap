# Reignited AP

For my wife, our time spent in these worlds is one of the greatest gifts
you've given me.

While nothing beats a classic there is a certain charm and magic to
Spyro Reignited Trilogy, so why not give it the Archipelago it deserves!
This project was originally started for my wife who wanted a tightly
coupled way to play the original Spyro trilogy. Seeing as all of the
games existed in one spot already, reignited was very appealing.
This project has been a labor of love and 4 weeks in it feels like the
right time to share it with everyone.

## Why Reignited AP?

- **Modernized experience** — quality-of-life improvements built on top of
the original foundation.
- **Community-driven** — shaped by feedback and contributions from people who
care about it.
- **Accessible to everyone** — designed so both new and returning users can
get started quickly.

## Getting Started

Head over to the [Releases](../../releases) page to grab the latest version,
then check out the installation instructions below to get up and running.

## Installation

1. Download the latest release from the [Releases](../../releases) page.
2. Extract it anywhere on your computer.
3. Run the launcher and point it at your Spyro Reignited Trilogy installation.
4. That's it — you're ready to play!

## Contributing

Contributions are welcome! Whether you want to fix a bug, add a feature, or
improve the documentation, your help is appreciated.

1. Fork the repository and create a new branch for your changes.
2. Make your changes, keeping the existing code style in mind.
3. Test your changes locally to make sure everything works.
4. Open a pull request with a clear description of what you changed and why.

If you're not sure where to start, check the open issues for good first tasks —
or open a new issue to discuss an idea before writing code.
